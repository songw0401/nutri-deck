# 국가표준식품성분 DB 기준 데이터

뉴트리 덱은 **메뉴젠 Open API를 서비스 실행 데이터의 원천**으로 사용하고, 국가표준식품성분 Database 10.4를 영양성분 기준 테이블로 사용합니다.

`national_food_10_4.tsv.gz.b64`는 사용자가 제공한 `식품성분표(10개정판)`의 국가표준식품성분 Database 10.4에서 현재 서비스 연계에 필요한 항목을 정규화한 파일입니다.

포함 항목:

- 식품명
- 식품군
- 출처
- 에너지
- 탄수화물
- 단백질
- 지방
- 식이섬유
- 당류
- 나트륨

영양성분은 100g 기준이며, 실제 메뉴 영양량은 메뉴젠 Open API의 재료 사용중량을 반영해 계산합니다.

## 연계 원칙

1. 메뉴젠 API의 재료명을 Unicode/공백 기준으로 정규화
2. 국가표준식품성분 기준 테이블에서 동일한 식품명이 **유일하게 존재할 때만** 자동 연결
3. 매핑되지 않는 재료나 필수 영양성분이 없는 재료가 포함된 메뉴는 게임 데이터에서 제외
4. 기존 `menuzen_ingredient.csv`는 이 연계 방식의 사전 검증에만 사용하며 런타임에는 읽지 않음

현재 검증용 메뉴젠 수집본의 22,582개 재료행은 모두 국가표준식품성분 기준 데이터와 exact-name 방식으로 연결되었습니다. 이 수치는 현재 검증 스냅샷의 **매핑 커버리지**이며, 향후 API 데이터 변경 시 동기화 과정에서 다시 검증됩니다.
