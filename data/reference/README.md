# 데이터 연계 기준 파일

뉴트리 덱은 **메뉴젠 Open API를 서비스 실행 데이터의 원천**으로 사용하고, 국가표준식품성분 Database 10.4를 버전이 고정된 영양 기준 테이블로 사용합니다.

## 파일

- `national_food_10_4.tsv.gz.b64`
  - 사용자가 제공한 `식품성분표(10개정판)`의 `국가표준식품성분 Database 10.4` 시트에서 현재 메뉴젠 식품명과 연계되는 항목만 정규화한 서비스 기준 테이블
  - 1,388개 식품, 100g 기준 영양성분
- `menuzen_food_crosswalk.tsv.gz.b64`
  - 기존 메뉴젠 API 수집본의 `food_Code`와 국가표준식품성분 DB 식품을 연결한 검증용 crosswalk
  - 1,425개 메뉴젠 식품코드가 포함됨
  - 모든 항목은 정규화된 식품명이 정확히 일치하며, 메뉴젠에 출처 정보가 있는 경우 국가DB 출처와도 일치하는지 검증함

## 런타임 매핑 원칙

1. API의 `food_Code`가 crosswalk에 있으면 검증된 국가DB 항목을 사용
2. 같은 코드의 식품명이 변경된 경우 기존 매핑을 강제하지 않고 식품명 exact match로 재검증
3. API에 새 `food_Code`가 추가된 경우 국가DB의 고유한 동일 식품명으로만 fallback 매핑
4. 식별되지 않거나 필수 영양값이 누락된 재료가 포함된 메뉴는 게임 데이터에서 제외

`menuzen_ingredient.csv` 자체는 런타임 원천 데이터로 사용하지 않습니다. 이 파일은 기존 API 수집본을 이용해 crosswalk를 검증하기 위한 개발 산출물입니다.
