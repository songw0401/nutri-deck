# 국가표준식품성분 DB 기준 데이터

이 폴더는 뉴트리 덱에서 메뉴젠 재료의 영양성분을 계산할 때 사용하는 **국가표준식품성분 Database 10.4 정규화 기준 데이터**를 보관합니다.

- 원본: `식품성분표(10개정판)`의 `국가표준식품성분 Database 10.4` 시트
- 서비스에서 사용하는 항목: 식품명, 식품군, 에너지, 탄수화물, 단백질, 지방, 식이섬유, 당류, 나트륨
- 저장소에는 현재 메뉴젠 재료명과 연계되는 항목만 정규화하여 TSV 파일로 분할 저장합니다.
- 영양성분 원본값은 100g 기준이며, 게임용 메뉴 영양량은 메뉴젠의 재료 사용량을 반영해 계산합니다.

이 파일들은 메뉴젠 API를 대신하는 캐시가 아니라 **필수 활용 데이터인 국가표준식품성분 DB의 서비스용 기준 테이블**입니다.
